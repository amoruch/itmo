	\section{Цель работы}
	Исследовать распределение случайной величины на примере многократных измерений определённого интервала времени.

	\section{Задачи}
	\begin{enumerate}
		\item Провести многократные измерения определённого интервала времени.
		\item Построить гистограмму распределения результатов измерения.
		\item Вычислить среднее значение и дисперсию полученной выборки.
		\item Сравнить гистограмму с графиком функции Гаусса с такими же, как у экспериментального распределения, средним значением и дисперсией.
	\end{enumerate}

	\section{Объект исследования}
	Объектом исследования является случайная величина --- результат измерения заданного человеком промежутка времени $t$. Разброс отдельных результатов обусловлен случайными особенностями задания и фиксации этого промежутка времени.

	\section{Метод экспериментального исследования}
	Метод состоит в многократном прямом измерении одного и того же заданного интервала времени цифровым секундомером телефона и последующей статистической обработке результатов. Для выборки из $N=50$ измерений вычислялись её статистические характеристики, строилась гистограмма и выполнялось сравнение с нормальным распределением.

	\section{Измерительные приборы}

	Измерения выполнялись цифровым секундомером телефона. Цена младшего разряда секундомера составляет $0{,}01$ с. В дальнейших расчётах принята абсолютная инструментальная погрешность

	\section{Рабочие формулы и обработка результатов}
	
	\subsection{Основные расчётные формулы}
	
	Для обработки результатов использовались следующие соотношения:
	\begin{itemize}
		\item среднее арифметическое (выборочное среднее):
		\[
		\langle t \rangle_N = \frac{1}{N} \sum_{i=1}^{N} t_i;
		\]
		\item выборочное среднеквадратичное отклонение:
		\[
		\sigma_N = \sqrt{\frac{1}{N-1} \sum_{i=1}^{N} \left( t_i - \langle t \rangle_N \right)^2};
		\]
		\item выборочная дисперсия:
		\[
		s^2 = \sigma_N^2;
		\]
		\item опытная плотность вероятности для каждого интервала гистограммы:
		\[
		\frac{\Delta N_i}{N \Delta t};
		\]
		\item теоретическая плотность нормального распределения (функция Гаусса):
		\[
		\rho(t) = \frac{1}{\sigma_N \sqrt{2\pi}} \exp\left( -\frac{(t - \langle t \rangle_N)^2}{2\sigma_N^2} \right);
		\]
		\item максимальное значение плотности нормального распределения:
		\[
		\rho_{\max} = \frac{1}{\sigma_N \sqrt{2\pi}}.
		\]
		\item среднеквадратичное отклонение среднего значения и итоговая погрешность:
		\[
		\sigma_{\langle t \rangle} = \frac{\sigma_N}{\sqrt{N}}, \qquad
		\Delta_{\text{сл}} = t_{\alpha,N}\sigma_{\langle t \rangle},
		\]
		\[
		\Delta_t = \sqrt{\Delta_{\text{сл}}^2 + \left(\frac{2}{\sqrt{3}}\Delta_{\text{инстр}}\right)^2},
		\qquad
		\varepsilon_t = \frac{\Delta_t}{\langle t \rangle_N}\cdot100\%.
		\]
	\end{itemize}

	\subsection{Итоговая погрешность результата}
	Для доверительной вероятности $\alpha=0{,}95$ и $N=50$ используем коэффициент Стьюдента $t_{0{,}95;50}=2{,}01$. Тогда
	\[
	\sigma_{\langle t \rangle}=\frac{\sigma_N}{\sqrt{N}}, \qquad
	\Delta_{\text{сл}}=t_{\alpha,N}\sigma_{\langle t \rangle},
	\]
	\[
	\Delta_t=\sqrt{\Delta_{\text{сл}}^2+\left(\frac{2}{\sqrt{3}}\Delta_{\text{инстр}}\right)^2},
	\qquad
	\varepsilon_t=\frac{\Delta_t}{\langle t \rangle_N}\cdot100\%.
	\]
	\par\smallskip
	Подстановка в формулы выполняется последовательно:
	\[
	\sigma_{\langle t \rangle}=\frac{\sigma_N}{\sqrt{N}}
	= \frac{0{,}47647}{\sqrt{50}} = 0{,}06738\ \text{с},
	\qquad
	\Delta_{\text{сл}}=t_{\alpha,N}\sigma_{\langle t \rangle}
	= 2{,}01\cdot0{,}06738 = 0{,}135\ \text{с};
	\]
	\[
	\begin{aligned}
	\Delta_t &= \sqrt{\Delta_{\text{сл}}^2+\left(\frac{2}{\sqrt{3}}\Delta_{\text{инстр}}\right)^2} \\
	&= \sqrt{0{,}135^2 + \left(\frac{2}{\sqrt{3}}\cdot0{,}01\right)^2} \\
	&= 0{,}136\ \text{с};
	\end{aligned}
	\]
	\[
	\varepsilon_t=\frac{\Delta_t}{\langle t \rangle_N}\cdot100\%
	= \frac{0{,}136}{9{,}667}\cdot100\% = 1{,}406\%.
	\]
	С учётом правил округления окончательный результат измерения имеет вид
	\[
	t = (9{,}67 \pm 0{,}14)\ \text{с}, \qquad \varepsilon_t = 1{,}4\%, \qquad \alpha=0{,}95.
	\]

	\section{Вывод}
	
	В ходе работы выполнено $N=50$ измерений заданного интервала времени цифровым секундомером. Получены выборочное среднее $\langle t \rangle_N=9{,}667$ с, выборочное среднеквадратичное отклонение $\sigma_N=0{,}476$ с и дисперсия $s^2=0{,}227$ с$^2$. Максимум рассчитанной плотности нормального распределения составил $\rho_{\max}=0{,}838$ с$^{-1}$.

	Для интервала $\langle t \rangle_N\pm\sigma_N$ экспериментальная доля результатов равна $0{,}60$, тогда как для нормального распределения она равна $0{,}683$. Для интервалов $\pm2\sigma_N$ и $\pm3\sigma_N$ экспериментальные доли равны $1{,}00$ при теоретических значениях $0{,}954$ и $0{,}997$. Эти различия объясняются конечным объёмом выборки и не противоречат качественному сходству гистограммы с кривой Гаусса.

	С учётом случайной и инструментальной погрешностей итоговый результат измерения интервала времени равен $t=(9{,}67\pm0{,}14)$ с при доверительной вероятности $\alpha=0{,}95$; относительная погрешность составляет $1{,}4\%$.

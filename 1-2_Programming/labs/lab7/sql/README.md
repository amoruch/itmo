# Локальная база ЛР-7

Скрипты рассчитаны на PostgreSQL и таблицы в схеме `public` базы `lab7`.
Они не удаляют существующие данные. Скрипт первоначального заполнения запускается
только один раз на пустой базе.

Из корня репозитория выполните в PowerShell:

```powershell
$psql = 'C:\Program Files\PostgreSQL\17\bin\psql.exe'
& $psql -U postgres -d lab7 -f sql/01_create_schema.sql
& $psql -U postgres -d lab7 -f sql/02_seed_collection.sql
& $psql -U postgres -d lab7 -f sql/04_replace_enum_checks.sql
& $psql -U postgres -d lab7 -f sql/03_verify_data.sql
```

Первый скрипт создаёт таблицы пользователей и `SpaceMarine`, а также индекс
по владельцу. Поле `id` — `GENERATED ALWAYS AS IDENTITY`: PostgreSQL создаёт
его сам; Java-код не должен указывать `id` в обычном `INSERT`.
Категории и типы оружия находятся в отдельных справочных таблицах; поля
`category` и `melee_weapon` ссылаются на них внешними ключами. Четвёртый
скрипт нужен только для уже созданной базы со старой версией `CHECK`-ограничений.

Второй скрипт переносит семь записей из текущего `collection.json`. Старые
`id` намеренно не переносятся — при импорте и в дальнейшем их выдаёт база.
Для перенесённых объектов создаётся пользователь `initial_import` с паролем
`initial-import`. В базе хранится только SHA-224-хэш. Также скрипт создаёт
три учётные записи для проверки доступа: `captain` / `captain-pass`, `scout` /
`scout-pass` и `medic` / `medic-pass`.

Третий скрипт выводит количество строк, пользователей, объекты с владельцами и
созданные индексы. После первого запуска ожидаются 4 пользователя и 7 объектов.

# Практика по программированию

Материалы и примеры для практических занятий по Java в ИТМО.

## Уроки

| Папка | Тема |
| --- | --- |
| `lesson_2_1/java` | Типы данных, классы-обёртки и преобразования |
| `lesson_2_2/java` | Обобщения (generics) |

Каждый пример можно скомпилировать из соответствующей папки `java`:

```powershell
javac -d bin src/App.java
java -cp bin App
```

Краткая теория и команды собраны в [cheatsheet.md](cheatsheet.md).
